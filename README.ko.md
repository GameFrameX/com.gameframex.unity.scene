## 프로젝트 개요

GameFrameX의 Scene 씬 관리 컴포넌트.

**Scene 씬 관리 컴포넌트 (Scene Component)** - 씬 관리 컴포넌트 관련 인터페이스를 제공합니다.

## 빠른 시작

### 설치 (선택)

1. `manifest.json` 파일의 `dependencies` 섹션에 다음 내용을 추가합니다:
   ```json
   {"com.gameframex.unity.scene": "https://github.com/AlianBlank/com.gameframex.unity.scene.git"}
   ```

2. Unity의 `Package Manager`에서 `Git URL`을 사용하여 추가: https://github.com/AlianBlank/com.gameframex.unity.scene.git

3. 저장소를 직접 다운로드하여 Unity 프로젝트의 `Packages` 디렉토리에 배치합니다. 자동으로 로드됩니다.
