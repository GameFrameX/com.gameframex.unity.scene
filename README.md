## Quick Start

### Installation (choose one)

1. Add the following to the `dependencies` section of `manifest.json`:
   ```json
   {"com.gameframex.unity.scene": "https://github.com/AlianBlank/com.gameframex.unity.scene.git"}
   ```

2. Add via Unity's `Package Manager` using `Git URL`: https://github.com/AlianBlank/com.gameframex.unity.scene.git

3. Download the repository directly and place it in the Unity project's `Packages` directory. It will be auto-loaded.
