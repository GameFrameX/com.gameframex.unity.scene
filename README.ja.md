## プロジェクト概要

GameFrameX の Scene シーン管理コンポーネント。

**Scene シーン管理コンポーネント (Scene Component)** - シーン管理コンポーネント関連のインターフェースを提供します。

## クイックスタート

### インストール（いずれかを選択）

1. `manifest.json` の `dependencies` セクションに以下を追加します：
   ```json
   {"com.gameframex.unity.scene": "https://github.com/AlianBlank/com.gameframex.unity.scene.git"}
   ```

2. Unity の `Package Manager` で `Git URL` を使用して追加：https://github.com/AlianBlank/com.gameframex.unity.scene.git

3. リポジトリを直接ダウンロードして、Unity プロジェクトの `Packages` ディレクトリに配置します。自動的に読み込まれます。
